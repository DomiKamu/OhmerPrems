**FRANKE MODULE - SPECIFICATIONS & QUICK GUIDE**

![](_img/FranKe.png)

As "kind of complement" of _FroeZe_ trigger-based sequencer (mainly from drums), _FranKe_ module is a 80HP quantized note-based sequencer, as requested by an (old) OhmerPrems member!

_FranKe_ (also a tribute to Christopher Franke, member of Tangerine Dream band) is providing 64 patterns, 8 tracks per pattern, 16 steps per track.

Track 8 may be replaced by a powerful 16-bit Turing Machine (state is always saved/recalled). In this case, the previous content of track 8 is hidden, and fully restored in case you close the Turing Machine.

:warning: Regular note-based track 8 and Turing Machine cannot used at the same time!

Each track have its own **PITCH**, +10V **GATE**, and (optional to use) **VELOCITY** output jacks.

:warning: **FranKe module is not an instrument**, but a voltage-based sequencer, who sends voltages in order to control other modules:
- **PITCH** to any sound source module such VCO/oscillator, synth voice, sampler, having **V/OCT** or **PITCH** input.
- **GATE** who output 0V or +10V gate voltage, to control an envelope generator module.
- **VEL.** (usage is optional), who send additional control voltage related to velocity.

- Like future (in development) 6OP-DX synth voice module, eight models (GUI theme variations) are available, like most Ohmer & OhmerPrems modules: compliant with **Prefer dark panels if available** feature (from **View** menu, since VCV Rack v2.4.0). Possible models are **Aluminium** (it's the default model if _Prefer dark panels if available_ option is disabled), **Stage Repro**, **Cobalt**, **Absolute Night** (it's the default model if _Prefer dark panels if available_ option is enabled), **Dark "Signature"**, **Fort Knox "Signature"**, **Oxide "Signature"**, and **Titanium "Signature"**. All "Signature" models embed gold metal jacks, buttons, and screws (instead of silver for non-"Signature" models). Obviously, all models provide exactly the same features!

FranKe module is under development, it will be available soon...

----

Free version (without license V2 keyfile) is working as **full player** (patches made by OhmerPrems members can be used without any restrictions - except... editing). Only track 1 can be edited (any pattern), other note-based track 2 to 8 are locked (bottom STEP encoders are inoperative on these tracks). However, the Turing Machine (track 8 substitution) is fully usable, all parameters can be changed. All stuff is saved and recalled.
